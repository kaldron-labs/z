# Zf source contract

## Overview

Reflection-backed field metadata and codecs for JSON, CBOR, D-Bus, ASN.1, CLI, URI, CSV, Cf, TOML and YAML, with shared owned configuration trees.

## Interface

- `ZfFieldTC` defines scalar/vector codes and extends ZuStruct metadata for keys, ordering, ranges, formatting and updates. `ZfVField`/`ZfVFieldType` describe type-erased fields, callbacks and enum/flags/UDT metadata. [ZfStruct.hh:ZfFieldTC] [ZfStruct.hh:ZfVField] [ZfStruct.hh:ZfVFieldType]
- `ZfJSON` parses mutable spans into tagged owned-node trees and supplies reflected object/array/map/string save/load/update handlers selected by facets and ADL formatting. JSON field properties control identifiers, omission and scalar formats. [ZfJSON.hh:scan] [ZfJSON.hh:AnyNode] [ZfJSON.hh:AsObject]
- `ZfStruct` macros register typed facets; field factories expose active metadata/key arrays and compiled ID matchers. Filters select constructor/load/save/update/delete fields. [ZfStruct.hh:ZfStruct] [ZfStruct.hh:ZfVFieldFactory] [ZfStruct.hh:ZfVKeyFields] [ZfStruct.hh:ZfFieldFilter]
- `ZfASN1` maps reflected fields to ASN.1 tags, positions, nesting and optional values, with object/array handlers and configurable stash/OID/vector storage. [ZfASN1.hh:Fmt] [ZfASN1.hh:AsObject] [ZfASN1.hh:AsArray] [ZfASN1.hh:ZfASN1_Config]
- `ZfDBUS` derives D-Bus signatures from reflected fields and supplies checked object/container/variant loading, measurement and serialization. [ZfDBUS.hh:signature] [ZfDBUS.hh:AsObject] [ZfDBUS.hh:AsVariant] [ZfDBUS.hh:save]
- `ZfURI` scans URI/path/form key-value input into string/array/object nodes and maps reflected fields via path/index/ID and scalar-format properties. Object/array/string/embedded-JSON adapters support save/construct/load/update. [ZfURI.hh:scanKey] [ZfURI.hh:AsObject] [ZfURI.hh:AsArray] [ZfURI.hh:AsJSON]
- `ZfCLI` maps short/long options, positional arguments and formatting properties onto reflected object/array/string/JSON handlers. Output adapters support stream/argv forms with raw, shell or command quoting. [ZfCLI.hh:ZuFieldProp::CLI] [ZfCLI.hh:Format] [ZfCLI.hh:OutStream]
- `ZfCBOR` scans binary items and serializes reflected object/array values without an intermediate node tree. Properties select keys/tags/optional fields; output uses compact numeric widths and encoded-key map ordering. [ZfCBOR.hh:handler] [ZfCBOR.cc:scan] [ZfCBOR.hh:saveValue]
- `ZfCSV` selects reflected columns for bounded push/pull record writers and streamed readers; handlers construct/load/update fields and customize quoted strings, bytes and vector formats. [ZfCSV.hh:Writer] [ZfCSV.hh:Reader] [ZfCSV.hh:saveValue]
- `ZfCf` parses configuration into owned ZfTree nodes and provides facet/filter-based object/container load/save. Grammar supports nested objects/arrays, quoted/bare tokens, comments, definitions and directive expansion. [ZfCf.hh:scan] [ZfCf.hh:handler] [ZfCf.cc:Scan]
- `ZfTree` owns heterogeneous arrays, ordered objects, scalar strings and dates with borrowed parent links. `ZfTOML` supplies bounded parsing and reflected object/container/union adapters with table-aware serialization. [ZfTree.hh:AnyNode] [ZfTOML.hh:Scan] [ZfTOML.hh:AsObject]
- `ZfTreeLoad` shares policy-driven typed construction/loading across configuration formats, including required/default fields, complete numeric scans, ranges, arrays and maps. [ZfTreeLoad.hh:Object] [ZfTreeLoad.hh:Array] [ZfTreeLoad.hh:Map]
- `ZfYAML` reuses owned tree and policy loaders, with reflected object/array/map/string/JSON adapters and selectable plain/quoted/block scalar styles. Save/update/delete filters emit block collections. [ZfYAML.hh:Scan] [ZfYAML.hh:AsObject] [ZfYAML.hh:ScalarFmt] [ZfYAML.hh:save]
- `libZf.la` installs codec, reflection and tree headers and links Ze, Zt, Zm and Zu. [Makefile.am:lib_LTLIBRARIES] [Makefile.am:pkginclude_HEADERS]

## Invariants

- Runtime get/set callback union selection trusts the caller-supplied type code. String/byte/UDT values may be borrowed pointers/spans; field IDs borrow metadata. Inactive/read-only fields do not permit ordinary writes. [ZfStruct.hh:VGet] [ZfStruct.hh:ZfVField] [ZfStruct.hh:ZfFieldWritable]
- Typed scalar/vector adapters supply defaults and formatting; writable setters forward to the underlying field while read-only setters are no-ops. Setters do not themselves enforce numeric ranges. Erased pointers must match their declared object/type. [ZfStruct.hh:ZfField_String] [ZfStruct.hh:ZfField_Int] [ZfStruct.hh:ZfField_IntVec]
- JSON node values/keys borrow mutable input even when nodes own child objects. Destination types determine whether loaded strings/bytes copy or borrow. Object handlers ignore unknown fields and invalidate duplicate recognized IDs; unresolved unions can retain node pointers. [ZfJSON.hh:AnyNode] [ZfJSON.hh:loadValue_] [ZfJSON.hh:Handler]
- JSON top-level scan accepts objects/arrays and reports consumed length without requiring end-of-input. Grammar permits unquoted keys, trailing commas and skipped comma positions; malformed parsing does not roll back input mutations. [ZfJSON.cc:scan] [ZfJSON.cc:eov_Object] [ZfJSON.cc:eov_Array] [ZfJSON.cc:eos]
- ASN.1 save requires consistent sizing/stash and emission passes over values. Load contexts borrow input spans; missing fields use defaults. Length/tag decoding distinguishes skippable mismatches from corruption without enforcing every DER canonicality constraint. [ZfASN1.hh:SaveContext] [ZfASN1.hh:LoadContext] [ZfASN1.hh:loadTL]
- D-Bus checked handlers require exact signatures, valid alignment/byte order/bounds and full consumption. Views and Any borrow immutable bytes/signatures. saveMeasured requires a stable measured object and reserved sink space; low-level loads do not roll back partial mutation. [ZfDBUS.hh:checkView] [ZfDBUS.hh:Reader] [ZfDBUS.hh:View] [ZfDBUS.hh:saveMeasured]
- URI nodes own children but borrow keys/value spans from mutable input. Repeated strings can promote to arrays, incompatible shapes fail, and path components use an empty-key array. Unresolved union values retain their node. [ZfURI.hh:AnyNode] [ZfURI.hh:string] [ZfURI.hh:path] [ZfURI.hh:Union]
- D-Bus validation enforces signature grammar, zero padding, text validity, array extent and full consumption; UnixFD signature syntax is accepted but value traversal is unsupported. ASN.1 scalar failures often produce defaults/null sentinels. [ZfDBUS.cc:validSignature] [ZfDBUS.cc:validate] [ZfDBUS.cc:skipValue] [ZfASN1.hh:loadValue_]
- CLI node values/keys and handler pointers borrow backing storage; owning Argv differs from span/pointer adapters. Required fields are checked before object operations, repeated scalar values fail, and array update touches the overlapping prefix. [ZfCLI.hh:AnyNode] [ZfCLI.hh:Argv] [ZfCLI.hh:Handler]
- CLI scans long/short options, positional fields and --, reporting malformed/unknown/missing values with contextual exceptions. InArgv normally borrows mutable arguments; copy mode destroys its owned temporary on return, so borrowed destination values cannot outlive it. OutArgv pointers borrow its owned strings. [ZfCLI.hh:scanArg] [ZfCLI.hh:scanArgv] [ZfCLI.hh:InArgv] [ZfCLI.hh:OutArgv]
- CBOR scan consumes one item and permits trailing bytes; conversions generally return defaults on type errors. Unknown map keys are ignored and duplicate recognized keys overwrite prior spans. Handlers borrow binary input; no explicit structural nesting limit is imposed. [ZfCBOR.cc:scan] [ZfCBOR.hh:loadValue] [ZfCBOR.hh:assign] [ZfCBOR.cc:Scanner]
- CSV row parsing borrows input and scratch row views exist only during callbacks. Input must remain writable, including delimiters used for NUL termination. Pull producer true continues and false ends; malformed/incomplete rows share the no-consumption result. [ZfCSV.hh:process_] [ZfCSV.hh:write] [ZfCSV.cc:split] [ZfCSV.cc:unquote]
- Cf parser borrows read-only source only during scanning and copies keys/scalars into the tree; all scalar spellings become String nodes. Full nontrivia consumption is required. CString/union/lazy-vector results can borrow tree storage and must not outlive it. [ZfCf.cc:scan] [ZfCf.cc:eos] [ZfCf.hh:Handler] [ZfTreeLoad.hh:LoadVec]
- Tree nodes are immovable and callers preserve tag/payload agreement. TOML unresolved unions borrow their tree node; table-shaped values route to tables/table arrays while empty arrays remain assignments. [ZfTree.hh:AnyNode] [ZfTOML.hh:AsUnion] [ZfTOML.hh:routeValue]
- Tree load assigns present/Reset/default fields while update assigns present/Reset update fields. Arrays update only the common prefix; map update replaces supplied keys and preserves absent ones. URI query keys require equals, and path/query plus handling differs. [ZfTreeLoad.hh:loadField] [ZfTreeLoad.hh:update] [ZfURI.cc:scanKey] [ZfURI.cc:eoc] [ZfURI.cc:eos]
- TOML rejects duplicate keys/table redefinitions and later extension of inline tables. Parser limits default to 128 recursive containers and 262144 nodes; dotted path length is not the recursive-depth limit. Embedded NUL ends parsing even when success reports full input length. [ZfTOML.cc:put] [ZfTOML.cc:checkHeader] [ZfTOML.hh:Limits] [ZfTOML.cc:run]
- YAML unresolved unions borrow tree nodes and serialize as null until resolved. Plain scalar/key checks fall back to quoted output for ambiguous values; optional omission depends on type and null/empty values. [ZfYAML.hh:Union] [ZfYAML.hh:plainScalar] [ZfYAML.hh:saveField]
- YAML scans one document and rejects tags/directives/complex keys/unquoted merge keys. Aliases target completed anchors and deep-clone nodes within alias/count/node limits; alias depth does not bound ordinary collection nesting. [ZfYAML.cc:run] [ZfYAML.cc:alias] [ZfYAML.hh:Limits]

## Side Effects

- Virtual-field formatting invokes getters/formatters and writes streams; scanning parses temporary scratch-backed values and calls setters. Enum/flags metadata uses singleton storage. [ZfStruct.hh:VGet] [ZfStruct.hh:VSet] [ZfStruct.hh:ZfVFieldType]
- Reference getters can borrow source storage; temporary string/byte/UDT results use thread-local scratch invalidated by later calls. UDT scanning synchronously passes a local parsed object to the setter. [ZfStruct.hh:ZfField_String_Get] [ZfStruct.hh:ZfField_Bytes_Get] [ZfStruct.hh:ZfField_UDT_Get] [ZfStruct.hh:ZfVFieldType_UDT_Scan]
- JSON decoding overwrites string escapes/terminators and can decode binary values in place. Load/update constructs or mutates objects/maps/arrays, while save appends to a stream. [ZfJSON.hh:eos] [ZfJSON.hh:loadValue_] [ZfJSON.hh:AsMap] [ZfJSON.hh:AsArray]
- ASN.1 handlers allocate or construct/mutate objects and use heap fallback beyond built-in OID/vector capacities. Optional/unsupported/out-of-range encodings can be omitted during sizing. [ZfASN1.hh:Handler] [ZfASN1.hh:LoadOID] [ZfASN1.hh:saveValue1_]
- D-Bus save measures before appending and can backpatch lengths. Checked load constructs/mutates objects and clears/refills containers; invalid checked loads are no-ops. [ZfDBUS.hh:save] [ZfDBUS.hh:Checked]
- URI decoding/splitting overwrites delimiters and compacts escapes in place. Handlers construct/mutate fields; output quotes/encodes values and embedded JSON builds a parse tree over the same mutable backing. [ZfURI.hh:eos] [ZfURI.hh:asArray] [ZfURI.hh:saveValue_] [ZfURI.hh:AsJSON]
- ASN.1 UTF conversion and URI binary conversion can overwrite input; decoded spans may borrow it. URI path loading can leave earlier fields changed after a later failure and return a borrowed remaining path. [ZfASN1.hh:loadValue_] [ZfURI.hh:loadValue_] [ZfURI.hh:loadPath_]
- CLI decoding/splitting mutates input delimiters; node helpers allocate trees and handlers construct or mutate objects without rolling back earlier fields. [ZfCLI.hh:eos] [ZfCLI.hh:asArray] [ZfCLI.hh:AsObject]
- InCLI records redirection spans and command separators without executing them. Field loads decode bytes in place and assign sequentially; later exceptions can leave earlier input/fields changed. [ZfCLI.hh:InCLI] [ZfCLI.hh:loadValue_] [ZfCLI.hh:load]
- CLI tokenization strips quotes/escapes and compacts/zero-fills the caller buffer; unmatched quotes or trailing escapes throw. CBOR save appends encoded bytes and owning string conversions can coalesce chunks into scratch storage. [ZfCLI.cc:eos] [ZfCBOR.hh:saveValue] [ZfCBOR.hh:stringValue]
- CSV loads unquote and decode binary values in place; header matching can mutate header bytes even on failure. Writers emit complete bounded records through a retained output reference and latch overflow. [ZfCSV.cc:unquote] [ZfCSV.hh:matchHdr] [ZfCSV.hh:write]
- Cf expands definitions or environment variables and synchronously invokes directive callbacks. Definitions, callback effects and destination field changes are not rolled back on later failure. [ZfCf.cc:eod] [ZfCf.cc:eos] [ZfTreeLoad.hh:Object]
- TOML serialization appends directly and can leave partial output on exceptions; union load/update can store borrowed node pointers. [ZfTOML.hh:saveEntry] [ZfTOML.hh:AsUnion]
- Tree map load clears its destination; update deletes keys before converting replacements. URI scanning percent-decodes/zero-pads input and builds nodes, without input rollback on failure. [ZfTreeLoad.hh:Map] [ZfURI.cc:scan]
- TOML scanning preserves source bytes while allocating copied tree values/keys and indexes; first failure records source coordinates. The convenience scan wrapper throws on failure. [ZfTOML.cc:addField] [ZfTOML.cc:bad] [ZfTOML.cc:scan]
- YAML save appends to its sink; union loading stores borrowed pointers, construction may allocate, and required-field diagnostics capture backtraces. [ZfYAML.hh:save] [ZfYAML.hh:Handler] [ZfYAML.hh:required]
- YAML parsing creates owned trees and throws source-coordinate diagnostics on failure. Flatten/merge consumes and mutates owned tree structure, repairs parent links, and can leave partial mutations on exceptions. [ZfYAML.cc:scan] [ZfYAML.cc:bad] [ZfYAML.cc:merge_] [ZfYAML.cc:flatten_]
