# Ztls tests

`make -C ztls/test test` runs the TAP tests, including `ZtlsKEMTest`,
`ZtlsX25519Test`, `ZtlsHybridTest`, and `ZtlsHPKETest`. The hybrid test checks the
MLKEM768-X25519 public key, encapsulated key and shared secret against
the first independent HPKE-PQ vector for KEM 0x647a. The HPKE test
checks recipient opening against that vector and sender round trips.
`ZtlsAgeTest` includes nineteen local [CCTV age testkit](https://github.com/C2SP/CCTV/tree/4448f2097b2daa812c91a26141f9f36c2096b9ca/age/testdata)
vectors covering X25519, scrypt, hybrid, unknown stanzas, mixed
hybrid/classical headers, forbidden scrypt mixing, non-canonical encodings,
low-order shares, recipient selection, scrypt work bounds, stream termination,
and liberal handling of well-formed unknown stanzas. The vectors are
embedded in `ZtlsAgeVectors.hh`, so the TAP suite needs no network or age CLI.
`ZtlsAgeSSHVectors.hh` embeds two reference-age-v1.3.2 ciphertexts with
unencrypted OpenSSH RSA and Ed25519 test identities. The TAP suite checks
SSH key loading and decryption of those independently produced files.

To exercise ML-KEM-768 PEM interoperability with the OpenSSL CLI in the
current build configuration, run from the repository root:

```sh
dir=$(mktemp -d)
./ztls/test/ZtlsKEMTest --save "$dir/z-private.pem" "$dir/z-public.pem"
openssl pkey -in "$dir/z-private.pem" -noout
openssl pkey -pubin -in "$dir/z-public.pem" -noout
openssl genpkey -algorithm ML-KEM-768 -out "$dir/openssl-private.pem"
openssl pkey -in "$dir/openssl-private.pem" -pubout -out "$dir/openssl-public.pem"
./ztls/test/ZtlsKEMTest --load "$dir/openssl-private.pem" "$dir/openssl-public.pem"
```

`ZtlsX25519Test` covers RFC 7748 vectors and RFC 8410 DER/PEM
round-trips. To check X25519 PEM interoperability in both directions:

```sh
dir=$(mktemp -d)
./ztls/test/ZtlsX25519Test --save "$dir/z-private.pem" "$dir/z-public.pem"
openssl pkey -in "$dir/z-private.pem" -noout
openssl pkey -pubin -in "$dir/z-public.pem" -noout
openssl genpkey -algorithm X25519 -out "$dir/openssl-private.pem"
openssl pkey -in "$dir/openssl-private.pem" -pubout -out "$dir/openssl-public.pem"
./ztls/test/ZtlsX25519Test --load "$dir/openssl-private.pem" "$dir/openssl-public.pem"
```

The temporary directories contain private-key material; remove them after
the interop checks using the platform's appropriate secure workflow.

`make -C ztls/interop ztlsageinterop` builds the optional Age interoperability
driver; it is not part of the TAP test target. It accepts
`encrypt|decrypt`, one of `x25519|hybrid|scrypt|ssh-rsa|ssh-ed25519`, a key
file, an input file, and an output file. SSH decryption also takes an SSH
authorized-key public file as the final argument. Native key files may be
generated by `age-keygen` (use `-pq` for hybrid); SSH public files use the
ordinary `ssh-rsa` or `ssh-ed25519` authorized-key line, and the driver
loads RSA/Ed25519 private keys in the PEM formats supported by `ZtlsPK`
and unencrypted OpenSSH private-key format. Password-protected OpenSSH
private keys are out of scope. Run it against a separately installed reference `age` CLI in both
directions, then compare the decrypted output byte-for-byte. The driver
keeps the reference CLI and its interactive passphrase prompting out of the
ordinary unit suite.
